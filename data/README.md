# data/

This directory holds local data files. Only `data/sample/` is tracked by git.

## Directory layout

```
data/
├── sample/                  # ✅ Committed — synthetic demo files (safe to share)
│   ├── HOLDINGS_*.csv       # Generated by data/generate_synthetic_data.py
│   ├── NAV_*.csv            # Generated by data/generate_synthetic_data.py
│   └── market_data_ALL.csv  # Generated by data/generate_synthetic_data.py
│
├── real/                    # ❌ Gitignored — real portfolio data (never commit)
├── cache/                   # ❌ Gitignored — Refinitiv fetch cache
├── generate_synthetic_data.py  # ✅ Committed — synthetic generator script
└── zero_coupon_yields.xlsx  # ❌ Gitignored — Refinitiv-fetched yield data
```

## Generating demo data

Run the synthetic generator to populate `data/sample/`:

```bash
python data/generate_synthetic_data.py
```

All outputs in `data/sample/` are randomly generated and contain no real ISINs,
market values, fund names, or client information. They are safe to commit and share.

## What must NOT be committed

See [UPLOAD_POLICY.md](../UPLOAD_POLICY.md) for the full policy. In summary:

- Any file produced by `integrations/refinitiv/fetch_market_data.py`
- Any real MVHOL or NAV files from a custodian
- `zero_coupon_yields.xlsx` (contains Refinitiv-fetched yield curves)
- Any file with real ISIN + market value pairs
